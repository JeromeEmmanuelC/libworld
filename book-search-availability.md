# Feature: Book Search and Availability

## User Story
As a library user, I want to search and view the availability of a book 
so that I can decide whether to borrow or reserve it.

## Description
This feature allows users to search the library catalog by title, author, 
or genre, and view real-time availability status for each book. If a book 
is unavailable, the user can choose to reserve it instead.

## Acceptance Criteria
- User can search books by title, author, or genre
- Search results display availability status (Available / Checked Out)
- User can initiate a reserve action for unavailable books
